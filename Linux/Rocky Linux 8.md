# Part 01. 리눅스 실무의 이해

## Chapter 01. 리눅스의 개요



운영체제: 컴퓨터 하드웨어와 컴퓨터 사용자 간의 매개체 역할을 하는 시스템 소프트웨어로 사용자가 프로그램을 실행할 수 있는 환경을 제공한다.

좁은 의미: 하드웨어와 응용 프로그램을 잇는 커널kernel

넓은 의미: 커널, 미들웨어, 응용 프로그램 실행 환경과 사용자 인터페이스 프레임워크를 모두 포괄하여 정의



운영체제의 분류

- 서버 운영체제: 하나의 서버에 다수가 접속하는 환경 기반 (웹 서버, 메일 서버, DNS 서버 등)
- 데스크톱 운영체제: PC에 탑재



유닉스 Unix

- 1969년, Bell 연구소 Ken Tompson
- System V 계열 / BSD 계열
- 다중 사용자, 다중 작업, 계층적 파일 구조, 가상 메모리 및 공유 라이브러리 지원





[www.gnu.org](https://www.gnu.org/)

GNU: GNU is Not Unix

- 유닉스와 호환되면서 더 강력한 운영체제를 만들고자 하는 프로젝트



FSF: Free Software Foundation

- 자유 소프트웨어의 생산, 보급, 발전을 목표로 만든 비영리 조직
- 소프트웨어를 실행, 복제, 학습, 개작, 향상시킬 수 있는 자유



[The Linux Kernel Archiveskernel.org](https://kernel.org/)

커널

- 운영체제의 핵심
- 시스템이 부팅될 때 로드된다
- 주된 역할은 시스템의 하드웨어 제어



주요 라이선스

- GPL General Public License

  - 컴퓨터 프로그램의 소스코드 용도에 따라 변경 가능
  - 변경된 프로그램도 소스코드 반드시 공개 배포

- LGPL Library/Lesser General Public License

  - 독점 소프트웨어에도 사용 가능
  - LGPL 라이브러리의 소스 코드 수정하는 경우 2차적 파생물 저작물에 해당하므로 라이브러리의 소스 코드 제공해야한다

- BSD Berkeley Software Distribution

  - 2차적 파생물에 대한 원시 소스 코드의 비공개 허용
- 소스 코드를 공개하지 않는 상용 소프트웨어에서도 사용 가능



리눅스 배포판: 리눅스 커널 이외의 핵심적인 부분을 GNU 정신을 바탕으로 만들어진 다양한 자유 소프트웨어와 공개 프로그램을 모아서 하나의 운영 체제로 만든 것
